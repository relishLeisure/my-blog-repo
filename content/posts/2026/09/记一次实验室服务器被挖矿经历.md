> **毫无疑问，这就是挖矿木马的“老巢”。**
>
> 这个目录下的文件特征已经完全拼凑出了一个完整的 **GPU 挖矿工具包**。你的判断非常准确，这就是被植入的恶意代码文件夹。

> 1. **`python` 和 `python3` (伪装的挖矿主程序)**
>    - 你可以看到 `python` 文件高达 **89MB**，`python3` 高达 **37MB**。正常的系统级 Python 解释器可执行文件通常只有几兆。这其实是黑客用 Go 语言或 C++ 静态编译的**挖矿主程序**（如 XMRig、NBMiner 等），为了在 `top` 或 `ps` 命令中掩人耳目，故意重命名为 `python`。刚才在网络连接里查到的 `513276/python` 进程，就是它跑起来的样子。
> 2. **`libnvrtc.so.\*` 和 `libnvrtc-builtins.so.\*` (NVIDIA 显卡调用库)**
>    - 这些是 NVIDIA CUDA 运行时编译库。黑客自带这些底层运行库，是为了即使你的服务器上没有正确安装 CUDA 环境，木马也能直接暴力调用你的 GPU 算力进行挖矿。
> 3. **`amdmemtweak` (AMD 显卡超频工具)**
>    - 这是一个专门用于调整 AMD 显卡显存时序的开源工具。挖矿圈常用它来“压榨”显卡的极限算力。
> 4. **`config.ini` 和 `Python.cfg` (木马配置文件)**
>    - 这大概率是挖矿的配置文件，里面通常会写明黑客的**矿池地址**（比如刚才网络连接里的外网 IP）和**钱包地址**。
> 5. **`run` (启动脚本)**
>    - 这通常是一个包含启动命令的 bash 脚本，用来加载上述的配置文件并后台静默运行那个巨大的 `python` 假程序。
> 6. **`top` (伪造的系统命令)**
>    - 正常系统的 `top` 命令通常在 `/usr/bin/top`。黑客在这里放一个 `top`，有时候是作为 Rootkit 的一部分，如果你不小心执行了它，它可能会故意过滤掉挖矿进程，让你以为系统负载很正常。
> 7. **`doos.pid` (进程锁文件)**
>    - 用来记录当前挖矿进程的 PID（进程号），防止启动多个挖矿进程导致服务器直接死机而暴露。

# 解决

## 1.通过定时任务定位

```bash
crontab -l
```

```bash
# 结果
* * * * * /var/tmp/.crond/upd >/dev/null 2>&1
```

这行 `* * * * * /var/tmp/.crond/upd >/dev/null 2>&1` 的意思是：**每分钟（五个星号代表每分钟）** 执行一次 `/var/tmp/.crond/upd` 这个脚本，并且把所有的输出和错误信息都丢弃（`>/dev/null 2>&1`），让你在日常使用中完全察觉不到。

值得注意的是，这个脚本指向的是 `/var/tmp/.crond/upd`，这说明除了你之前发现的 `/tmp/.crond`，木马在 `/var/tmp/` 目录下还放了一个备用的执行源。

> 这个目录下的文件结构是非常典型的自动化攻击脚本包：
>
> - **`a` / `upd` / `run`**：这些通常是 Shell 脚本，负责下载木马的更新、检查运行状态、并把自身写入 `crontab` 确保不死。
> - **`bash.pid`**：用来记录反弹 Shell 后门的进程号（PID）。
> - **`cron.d`**：伪造的定时任务目录名，可能存放了其他用于持久化的配置。
> - **`h32` / `h64`**：极其典型的恶意挖矿/后门程序二进制文件！它们通常代表针对 32 位和 64 位系统编译的木马实体。
> - **`java` / `x`**：黑客经常将恶意程序重命名为 `java` 等常见进程名，以躲避管理员的粗略检查。`x` 可能是一个隐藏的执行入口或脚本。

## 2.处理

### 第一步：删除定时任务

必须先删定时任务，否则后面的操作毫无意义。

1. 查看定时任务

   ```bash
   crontab -l
   # 输出
   * * * * * /var/tmp/.crond/upd >/dev/null 2>&1
   ```

2. 输入命令编辑当前用户的定时任务：

   ```bash
   crontab -e
   ```

3. 找到 `* * * * * /var/tmp/.crond/upd >/dev/null 2>&1` 这一行，将其彻底删除。

   - 如果是 `vi` 编辑器，将光标移动到该行，连续按两次 `d` 键（`dd`）即可删除。然后输入 `:wq` 按回车保存退出。
   - 如果是 `nano` 编辑器，直接用退格键删掉，然后按 `Ctrl+O` 回车保存，`Ctrl+X` 退出。

4. 再次运行 `crontab -l`，确认没有任何输出，或者该恶意行已被成功移除。

### 第二步：彻底击杀所有恶意进程

现在定时任务已经不在了，木马失去了“复活甲”，我们可以放心动手杀进程了。请依次执行：

```Bash
# 击杀挖矿木马主进程
kill -9 513276

# 击杀 IRC 僵尸网络进程
kill -9 299430

# 击杀反弹 Shell 进程
kill -9 298877

# 如果还不放心，可以用下面这条命令一键清理名为 python、crond 但在恶意路径下的漏网之鱼
pkill -9 -f "/tmp/.crond/python"
pkill -9 -f "/var/tmp/.crond/"
```

### 第三步：连根拔起，删除所有恶意文件

清理所有查出的木马目录：

```Bash
# 删除 /tmp 下的木马主目录
rm -rf /tmp/.crond
# 删除 /var/tmp 下的更新脚本或备份目录
rm -rf /var/tmp/.crond
```
