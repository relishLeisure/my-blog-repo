# 家乡在东极岛

故事从东极岛展开，[《东极岛之歌》](https://www.bilibili.com/video/BV1D341127xk/)

```txt
《东极岛之歌》
东极岛啊 你人杰又地灵
太平洋的风儿最先吹到你
东极岛 东极岛
大陆最东的岛屿
海浪都来亲吻你
鱼儿都来拥抱你
东极岛 你是人间的仙境
太平洋的阳光它最先照耀这里
东极岛 东极岛
我们不会离开你
生是你的老百姓
死是你的小精灵
东极岛啊 东极岛啊
除了这里
我们哪儿都不想去
```

从小受到的教育，家乡是人杰地灵，国家是地大物博，人民是勤劳质朴

文字描述的是缺乏的东西，稀缺才像看爽文一样，在幻想中在脑海中得到满足

激昂的歌词配上萧条的画面，起开家乡久了，再回到家乡

会发现家乡的房子原来这么矮，路这么窄，这么破旧

原来我的家乡很平凡

# 周沫姐

见到周沫姐，以为是民国的贵妇人，原来是他人的替身

没有家庭没有背景，大城市相对小地方公平

如果有家庭有背景，那么在大城市会更公平

穿着学生服，理想倒在枪口下

# 苏米

苏米和家人被骗了，于是他们也去骗人

不去借钱，因为借钱就是骗朋友的钱

仙人跳，骗的是嫖客的钱

小孩子才论好坏，成年人只看利弊

他们的确更厚道些

# 胡生

胡生在心目中，很崇拜浩瀚哥和江河，因为只有他们不说他脑子不正常

胡生被弄丢之后，浩瀚哥和江河其实也认为他不正常

我也是胡生，自命不凡，在别人眼中十分不正常

原来我自己很平凡

# 刘莺莺

浩瀚哥要去见刘莺莺，以为是自己迷倒了对方

其实他们同父异母，有血缘关系

他们的通信，起因是浩瀚哥的父亲还关心他

浩瀚哥记忆中，父亲在台风天出海而死，是不惧怕风雨的勇敢者

现实中，父亲喝醉酒后抽烟，被烧死了

像社会新闻，死得很平凡

原来我们的父母很平凡

# 旅行者

来自东莞的旅行者，不说姓名，只说自己叫`旅行者2号`

他说小学追了女同学七年，后来女生真成了他的妻子，把她的照片印在头盔上

他骑行想证明自己，除了妻子无人关心

他说的英文编号，江河也知道，想必确有其事

他是理想者还是骗子？为什么取得信任之后，盗走了浩瀚哥的车子？

他可能真的曾有梦想，只是生活还得继续，梦想既是他的追求，也是他的谋生手段

就和旅行者二号一样，想去追赶旅行者，半途爆炸了

描绘理想的人也很平凡

# 结语

> 世界很平凡，每个人都撒谎，与自己和解吧
>
> 接纳自己，相信自己，守护自己的本心
