Tailscale使用记录 August 28, 2026

设置流量转发节点¶

Linux下载安装Tailscale¶ 
sudo mkdir -p /etc/apt/sources.list.d/
curl -fsSL https://tailscale.com/install.sh | sh

登录

sudo tailscale up

开启ip转发

echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
echo 'net.ipv6.conf.all.forwarding = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
sudo sysctl -p /etc/sysctl.d/99-tailscale.conf
设置流量出口节点 Exit Node¶

其他机器流量经过这个设备转发

sudo tailscale up --advertise-exit-node

在 Tailscale 控制面板中批准 Authorization

出于安全考虑，宣告后并不会立刻生效，必须在后台手工允许：

  1. 打开 Tailscale Admin Console (Machines 页面)。
  2. 找到你刚配置的这台 Linux 设备。
  3. 点击设备右侧的 ... (更多选项) -> 选择 Edit route settings。
  4. 勾选 Use as exit node。
  5. 点击 Save。
